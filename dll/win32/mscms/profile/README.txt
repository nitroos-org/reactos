sRGB Color Space Profile.icm
============================
The default sRGB display profile of ReactOS (system32\spool\drivers\color). It is the file that
GetStandardColorSpaceProfile(LCS_sRGB) names, under the file name Windows uses.

Provenance: generated by genicc.py in this directory; nothing is taken from another profile, from a
Microsoft file or from a third-party package. Inputs are public standards only: the sRGB transfer curve of
IEC 61966-2-1 (1024 samples), the Rec. 709 primaries adapted to the ICC D50 profile connection space
(Bradford; the usual published matrix) and the ICC D50 white point. Licence: CC0-1.0 (public domain
dedication); the generator is under the same licence.
